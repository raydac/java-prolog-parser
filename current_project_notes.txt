## 2. Architecture & Technical Discoveries
- Tokenizer is a per-character state machine. Operator scan uses `String` prefix lookups on every extension.
- `doReadChar()` calls `Reader.read()` one char at a time. It is not synchronized; the tokenizer is single-threaded. A lock on that method alone made SpotBugs treat position fields as cross-thread state.
- Numbers are `BigInteger` / `BigDecimal`. `PrologNumeric.getType()` returns `TermType.ATOM`.
- Phrase parser builds an `AstItem` tree, then `convertToTermAndRelease`.
- Integer-to-float transition now stores `E` as `e`. A second exponent marker ends the number and is pushed back.
- `readStruct` returns null only for a real `f()`. A missing argument throws `PrologParserException`.
- `Tokenizer.close` on a `PushbackReader` unreads `insideCharBuffer` only.

## 3. Technical Debt & Refactoring
- Operator matching should be a trie (or first-char bitmap plus trie) so atoms do not allocate a `String` per character. `String.valueOf(chr)` on the first operator char has the same cost.
- Read chars from an internal buffer filled by `Reader.read(char[])`. `doReadChar()` is single-threaded.
- ASCII class table for whitespace / letter / digit / upper. `findQuotation` scans the finished atom a second time with `Character.*`.
- Parse integers through `long` and allocate `BigInteger` only on overflow. `PrologInt.getText()` calls `BigInteger.toString()` on every read.
- Copy `lastTokens` only when `getLastTokens()` is called. `TokenizerResult` always materializes `rawString`, including leading whitespace.
- Phrase parse builds an `AstItem` plus a `TermWrapper` per operator, then `convertToTermAndRelease` throws that tree away. `PrologStruct` clones the argument array.
- Atom text cannot be interned while `line`/`pos` stay mutable on the term.
- Floats are `BigDecimal`. Switching to `double` is an open semantic choice, not a silent optimization.
- `calcDiffAndPushResultBack` still resets the column to 1 when a pushed operator fragment contains a newline. Operator text does not contain newlines today.

## 5. Known Issues & Limitations
- `'don''t'` is rejected (backslash escapes only). Lone `.` is end-of-input by tests.
- Speed items in section 3 are not implemented.

## 6. Open Questions & Pending Decisions
- Whether float parsing may switch from `BigDecimal` to `double`.
- Whether ISO doubled-quote escapes should be accepted.
